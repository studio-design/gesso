# Prepare for Gesso 3.0

Gesso 3.0 removes the configuration keys, CLI spellings, and APIs that v2
deprecated. Upgrade to v2.9 first: every removal emits a
`[Gesso deprecation]` notice there, so a clean v2.9 run is a clean v3 upgrade.
The per-surface ledger lives in [`UPGRADING.md`](https://github.com/studio-design/gesso/blob/main/UPGRADING.md).

## Contract-check aliases

The `Studio\Gesso\Fuzz\` aliases of the named contract checks are gone
([#503](https://github.com/studio-design/gesso/issues/503); deprecated in
2.7.0). `ContractCheck`, `ContractCheckPlan`, `ContractCheckFailure`,
`ContractCheckSkip`, `ContractCheckSummary`, `OpenApiContractChecks`, and the
`@internal` `ContractCheckProbe` resolve only under `Studio\Gesso\Contract\`.
Generator types (`ExploredCase`, `OpenApiSpecExplorer`, ...) stay in
`Studio\Gesso\Fuzz\`.

```php
// Before (v2)
use Studio\Gesso\Fuzz\OpenApiContractChecks;
// After (v3)
use Studio\Gesso\Contract\OpenApiContractChecks;
```

The v2 notice did not fire for an old name referenced after the class was
already loaded, so search for `Gesso\Fuzz\ContractCheck` and
`Gesso\Fuzz\OpenApiContractChecks` rather than relying on a silent v2.9 run.

## Deprecated helper methods

`OpenApiCoverageTracker::hasAnyCoverage()` and the `SkipOpenApiResolver`
trait's private `shouldSkipOpenApi()` (composed into `ValidatesOpenApiSchema`)
are gone; both were deprecated in 2.7.0.

```php
// Before (v2)
OpenApiCoverageTracker::hasAnyCoverage('front');
$this->shouldSkipOpenApi();
// After (v3)
OpenApiCoverageTracker::current()->hasAnyCoverageOn('front');
$this->findSkipOpenApiAttribute() !== null;
```
